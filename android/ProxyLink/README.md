# ProxyLink (Android)

Otevři složku v Android Studiu (File > Open), počkej na Gradle Sync a spusť na telefonu (Run).
Minimální Android 8.0 (API 26).

Aplikace čeká na pozadí (notifikace "ProxyLink"), PC ji najde po Wi-Fi sama.
Při prvním spojení se otevře stránka s jednorázovým kódem, který opíšeš v ProxyLinku na PC.
